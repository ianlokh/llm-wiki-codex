# Reports

Durable, Markdown handoff logs from the ingestion and linting roles: changed paths, provenance recorded, unresolved gaps, and lint findings (blocking vs advisory). Kept outside `wiki/` so they never become query evidence, but retained for auditability of a closed-world corpus.

Suggested filename: `ingest-YYYY-MM-DD.md` or `lint-YYYY-MM-DD.md`.
